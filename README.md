# Sabrang Mart - LPG Gas Booking System v0.0.0.3 (Pre-Release)

An intuitive web-based application designed solely for practical use for both the administrator
and customers.

---

## Features

### Customer Portal
* **User Authentication:** Simple sign-up and login functionality for customer accounts.
* **Gas Booking:** Order LPG gas cylinders online with ease.
* **Account Management:** Manage personal profile details and booking history.

### Admin Portal
* **Admin Dashboard:** Access administrative controls to manage incoming orders.
* **Account Management:** Oversee customer accounts and system data.

---

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Deployment:** [Vercel](https://lpg-gas-booking-project.vercel.app)
